Inside the Container

What a user can measure about the privacy architecture of an AI conversation

When you talk to an AI, where does your conversation go? Who can read it? What is stored, and where?

This project provides a reproducible protocol for answering these questions from the user's side. Not by reading the provider's privacy policy. By measuring.

The Central Finding

The client-side architecture of a hosted AI conversation provides no user-verifiable privacy guarantee. The user's trust rests entirely on the provider's policy commitments.

Data CategoryProvider Can AccessUser Can Verify
Your messagesYesNo

Container network trafficYesNo

The privacy model of hosted AI conversation is the same as email: the server can read your messages. It is not the same as end-to-end encrypted messaging, where the server cannot.

How It Works

The script measures the execution environment using standard Linux tools: TCP connections, TLS certificates, filesystem configuration, process memory, transcript contents. It does not probe for vulnerabilities or reverse-engineer proprietary systems. It observes what is visible from within the environment provided to users.

The Paper

The full methodology, findings, and regulatory analysis are in the paper Inside the Container: What a User Can Measure About the Privacy Architecture of an AI Conversation (Colamedici, 2026, draft). The paper documents nine specific findings, a capability/policy/verifiability table, and a comparative privacy spectrum from hosted AI to end-to-end encrypted messaging to local open-weight models.
